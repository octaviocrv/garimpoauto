# App Icon — Garimpo Auto

Compositions for the Garimpo Auto app icon using the Han mascot.

## Variants
- **Teal Circle** — default, primary brand color
- **Black Circle** — dark mode / formal contexts
- **Off-White Circle** — jacket detail / light alternate
- **Teal Rounded Square** — iOS app icon style
- **Black Rounded Square** — dark iOS variant

## Rules
- Always use white border between mascot and background
- Minimum size: 32px (below this, mascot details are lost)
- Image is cropped to show face only, positioned slightly above center
