Button is the primary interactive element. Use for CTAs, form actions, and navigation.

```jsx
<Button variant="primary" size="md">Ver carros</Button>
<Button variant="secondary">Criar anúncio</Button>
<Button variant="ghost" size="sm">Cancelar</Button>
<Button variant="gold">Oferta especial</Button>
```

Variants: primary (teal), secondary (black), ghost (teal outline), outline (slate), gold (special), dark (black).
Sizes: sm, md, lg.
